# Singularity

**Forecasting where science goes next, then testing it.**

Singularity reads the scientific literature to forecast which methods will move into which fields. When a forecast
looks promising, we run the study ourselves: the plan is fixed before looking at the results, the test is run once,
and everything needed to check it is published here, from the paper to the code and the raw results.

## Research

| study | in one line |
|---|---|
| [One formula for the overtones of spinning black holes](https://github.com/singularity-sd/kerr-qnm-overtones) | A single closed-form fit for Kerr quasinormal overtones up to near-extremal spin. |
| [Waiting for the slowest](https://github.com/singularity-sd/fork-join-queues) | An approximation for the mean response time of fork-join queues with general service times, tested once. |
| [Do universal AI potentials find the shape of atomic clusters?](https://github.com/singularity-sd/cluster-mlip-benchmark) | A preregistered benchmark of universal machine-learned interatomic potentials on isolated clusters of 55 elements. |
| [A learned Fourier correction for smoke simulation](https://github.com/singularity-sd/learned-smoke-correction) | From a v1 forecast: 8.8% less error than the best classical solver at the same speed, with eight learned numbers. |
| [Kolmogorov–Arnold layers inside an Energy Flow Network](https://github.com/singularity-sd/kan-energy-flow-networks) | From a v2 forecast: Kolmogorov–Arnold layers beat a jet tagger six times larger on every test file. |
| [Sparse L1 classification of medical abstracts](https://github.com/singularity-sd/lasso-medical-abstracts) | From a v3 forecast: LASSO beats ridge on medical abstracts using under 1% of the coefficients. |
| [Crystal structure versus composition for unseen perovskites](https://github.com/singularity-sd/perovskite-structure-vs-composition) | From a v3 forecast: for unseen perovskite formulas, a crystal graph network cuts the error about seven times. |
| [Contrastive pretraining for Tox21 on unseen scaffolds](https://github.com/singularity-sd/tox21-contrastive-scaffolds) | From a v3 forecast: contrastive pretraining improves Tox21 prediction on all 12 assays for unseen chemical families. |
| [When a test pays off at dry-off](https://github.com/singularity-sd/dry-off-decision-curves) | Decision curve analysis for selective dry-cow therapy, from a Singularity v3 forecast. |
| [One placebo arm for every season](https://github.com/singularity-sd/platform-trial-shared-placebo) | Platform trials for atopic dermatitis: sharing a placebo arm across seasons, a pre-specified simulation from a Singularity v3 forecast. |
| [The rare failure trap](https://github.com/singularity-sd/smote-rare-failure-trap) | What SMOTE oversampling does to surrogate-based failure probabilities in structural reliability, from a Singularity v3 forecast. |
| [Subtypes that are not there](https://github.com/singularity-sd/null-calibrated-subtypes) | Null-calibrated consensus clustering for cognitive test batteries: which procedures invent subtypes, from a Singularity v3 forecast. |
| [Catching a turbine wearing down](https://github.com/singularity-sd/wasserstein-turbine-monitoring) | Wasserstein distances for wind-turbine power-curve monitoring: a pre-specified simulation comparison, from a Singularity v3 forecast. |

Each repository holds the paper (PDF and LaTeX), the code that reproduces it and the results.
All papers are preprints, not yet peer reviewed.
